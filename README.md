# fabric_data_system
Учебный курсовой проект - Информационная система мебельной фабрики

Архивный проект | 2024 год | Python MySQL

---
## О проекте

- Разработка базы данных MySQL на основе анализа предметной области
- Разработка интерфейса для взаимодействия с базой данных (Tkinter)

## Возможности

- Взаимодействие со всеми сущностями базы данных
- Просмотр/Добавление/Изменение/Удаление записей через интерфейс
- Вывод результатов пользовательских запросов через процедуры
